# STARTAK — تنفيذ جميع المسارات في دفعة واحدة

أمر التشغيل الموحد:

```sh
node tools/verify-all-stages.mjs --out-dir=/tmp/startak-one-batch
```

ينفذ الأمر فحص الإصدار الكامل، وإعادة إنتاج مرجع التمويل المستقل ومقارنته، وفحوص Chromium للسوق والتدقيق والهوية والعوائد المؤرخة، ورحلة الأصول الثلاثة عشر بالعربية والإنجليزية، ورحلة المالك على الحاسوب والهاتف وتنزيل التقارير. يُشغّل كل فحص حتى عند فشل سابق، ويحتفظ بسجل منفصل لكل أمر وبنتيجة واحدة على الالتزام نفسه. يشترط تثبيت تبعيات المشروع وChromium قبل التشغيل.

يعقب ذلك رصد قراءة فقط للمعاينة وللمسارين الموجودين public-config وai-assist. لا تتبع المراقبة تحويلات تسجيل الدخول، ولا تقرأ محتوى الاستجابة أو تحفظ كوكيز أو مفاتيح. عند إتاحة المعاينة تتحقق الأداة الأصلية من بصمة الالتزام وكل الأصول؛ استجابة HTTP ناجحة منفردة لا تثبت ذلك أو تشغيل ذكاء حي.

المخرجات في GitHub Actions artifact: `all-stages.json` و`all-stages.md` والسجلات الحسابية وسجل متطلبات الأدلة الخارجية Q01–Q12، البالغ 36 متطلبًا وفق البرنامج الحالي. إعداد سجل المتطلبات ليس إرسالًا لطلبات أو إثبات تعيين أشخاص أو اعتماد مستقل.

رمز الخروج 1 يعني فشل فحص هندسي أو غياب دليل تنفيذ مطلوب. رمز الخروج 2 يعني أن الفحوص الهندسية نجحت لكن التأهيل الشامل ما زال HOLD. لذلك قد تنجح Release Verify بينما يبقى مسار One Batch Qualification غير ناجح؛ لا يُفسر ذلك بأنه عطل حسابي أو جاهزية كاملة.

تظل بيانات الصفقات المرخصة والعينة المستقلة، وإثبات فاتورة واستجابة مزود ذكاء حي، واختبار هويتين مصادقتين وعزل جهتين فعليًا، والتوقيعات المستقلة المالية والأمنية والقانونية والمهنية أدلة خارجية غير مقدمة لهذا المشغل. لا يستنتج غيابها من أعطال HTTP، ولا يستبدلها بمحاكاة أو تصريح المالك. تظل D04 وD05 جزئيتين حتى اكتمال شروط إغلاقهما؛ يغطي فحص اللغة المسارات المختبرة ولا يمنح شهادة تغطية شاملة.
