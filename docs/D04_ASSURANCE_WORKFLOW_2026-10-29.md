# D04 — تدقيق التقييم وجودة الأدلة وحوكمة النتائج

أضيفت العربية والإنجليزية والاتجاه المناسب إلى واجهات تدقيق تقرير التقييم، وبوابة جودة الأدلة وقائمة اكتمال التقرير، ومعرّف حالة المستندات، ومتابعة النتائج، وضبط الدروس ومقترحات التغيير، وتأهيل التغيير الهندسي.

تشمل ترجمة التدقيق بيانات التقرير الحالي والسابق، والتحقق الحسابي والدوران في الاستدلال، وحالة ربط التدقيق بدراسة السوق. تُعرض رسالة الربط باللغة الحالية عند تبديلها دون إعادة تنفيذ الربط. تُترجم كذلك الحقول القطاعية للفنادق والمراكز التجارية والمستودعات والخدمات اللوجستية ومحطات الوقود. تستخدم المبالغ تنسيق اللغة دون تغيير قيمها الحسابية.

تقتصر الترجمة على النصوص النظامية. تبقى أسماء العقارات والملاك ومراجع المستندات والروابط وملاحظات المصدر ومدخلات المستخدم على صيغتها الأصلية. تُعرض رموز التشخيص الأصلية في عناصر محمية من تغيير النص. لا تدخل اللغة في محركات الحساب أو قرارات المنع أو التحقق المهني أو سجلات الحفظ.

## التحقق

- اختبار React محلي بعناصر DOM محاكية، وليس متصفحًا فعليًا، يغطي اللغتين والحقول الحالية والمرتبطة، ورسالة إجراء سابقة، وأرقامًا عربية، والحالات القطاعية الخمس، ونصوص جودة الأدلة والحوكمة وحدود الصلاحيات. يفحص ترجمة كل أسباب بوابة الجودة وكل بنود قائمة التقرير، وعدم تعديل كائنات المصدر أو بيانات الحوكمة.
- اختبار Chromium على GitHub يبدل AR→EN→AR مع وجود تقريرين وتعارض حسابي وربط ذي HOLD. يقارن كل قيمة وخيار ومربع اختيار قبل التبديل وبعده، ويتحقق من ترجمة أسماء الوصول والتحذيرات والأرقام، ومن استمرار المنع. يكرر فحص الحقول القطاعية للحالات الخمس مع مراجع ومبالغ عربية مدخلة.
- تؤخذ نتائج الإصدار وعدد الاختبارات وحالة المعاينة من تشغيل CI المطابق لرأس PR؛ لا تنتقل نتائج الالتزام السابق تلقائيًا إلى هذه الدفعة.

## حدود الإغلاق

D04 ما زال PARTIAL حتى استكمال النصوص المتبقية في بقية الأقسام التحليلية وفحص تغطية الواجهة كاملة. إبقاء نص المصدر بلغته الأصلية مقصود، ولا تُعامل ترجمته كتحقق من أصالته. تظل D05 والتكاملات الحية والصلاحيات والمراجعة المهنية وفق أدلتها السابقة. قرار الاستخدام الاستثماري المعتمد HOLD / NOT_AUTHORIZED، وPR #766 لا يزال مسودة غير مدمجة.
