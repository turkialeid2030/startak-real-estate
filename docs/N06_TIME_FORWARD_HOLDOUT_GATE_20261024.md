# N06 / C56 — ضابط الاختبار التاريخي دون تسرب معلومات مستقبلية

تاريخ التغيير: 24 أكتوبر 2026. المرجع: #615 و#658 و#622.

## المنجز في هذه الدفعة
- إضافة بوابة قابلة للتنفيذ في src/validation/time-forward-valuation-holdout.js فوق حاسبة الأخطاء الحالية، دون تغيير المعادلات الأصلية أو إلغاء الحراس القائمة.
- اشتراط بروتوكول محدد مسبقًا: تاريخ تسجيل البروتوكول، تاريخ قطع التدريب، نافذة العينات المستقبلية، إصدار النموذج، العملة وأساس التقييم، الحدود العددية، مجموعات المعايرة، الشرائح المستهدفة وحد كل شريحة.
- منع تضمين عقارات المعايرة في عينة الاختبار، وتكرار الصفقة/الأصل/مرجع المصدر، وعدم تطابق إصدار النموذج أو العملة أو أساس القيمة.
- رفض تسجيل توقع بعد تاريخ المعاملة أو قبله بطريقة تناقض تاريخ تقييم النموذج، واستخدام معاملة خارج نافذة الاختبار.
- احتساب P90 للخطأ المطلق النسبي بطريقة nearest-rank مع إظهار خطأ الوسيط والمتوسط من الحاسبة القائمة؛ لا يمر اختبار العينة إذا تجاوز P90 السقف المحدد أو نقص عدد الملاحظات ضمن الشرائح.
- تضمين بصمة SHA-256 لمحتوى البروتوكول لتعقب التغييرات، مع بيان صريح بأن إعادة حساب البصمة لا تثبت تاريخ التسجيل أو الصلاحية أو مصدر المستند.
- إضافة اختبارات في tests/defects/time_forward_valuation_holdout.js؛ يكتشفها release:verify تلقائيًا.

## شكل البروتوكول
الحقول الإلزامية: protocolId، registeredAt، trainingCutoffDate، holdoutStartDate،
holdoutEndDate، modelVersion، currency، basis، calibrationAssetIds،
maxP90AbsolutePercentageError، numericPolicy، slices من region أو assetType مع minObservations.

كل حالة تحتاج حقول محرك المقارنة الخارجية الحالي، إضافة إلى:
region، assetType، modelVersion، predictionRecordedAt.
تُستعمل تواريخ ISO بصيغة YYYY-MM-DD. العينة محصورة في 10,000 سجل في كل استدعاء.

## ما لا يمكن اعتباره مغلقًا
- جميع أدلة الاختبار المصطنع مجرد تأهيل هندسي؛ لا يوجد سجل صفقات سعودي موثق أو مجموعة holdout حقيقية مرفقة هنا.
- لا يمكن للبصمة أو قيمة reviewerRef النصية إثبات أن مصدر الصفقات مصرح أو مستقل؛ يجب التأكد خارج النظام من صحة البايتات والحقوق والوقت والتوقيع.
- النموذج لا يثبت استقلالية التقييم أو حدود الثقة الإحصائية أو صلاحية استخدامه لدى خبير مثمن معتمد.
- حالة CALCULATED_WITHIN_REGISTERED_THRESHOLDS تعني نجاح حسابات العينة المقدمة فقط، وتبقى أعلام independentMarketEvidenceVerified، sourceRightsVerified، licensedValuerApproved، statisticalConfidenceEstablished، certifiedValuationEstablished، productionDecisionAuthorized بقيمة false.
- لم تُشبك البوابة مع مسار اعتماد تقارير العقارات أو نشر قيم السوق؛ لا يجوز عدّها إغلاقًا كليًا للبند N06.

## متطلبات الإغلاق الخارجية
1. مالك البيانات: حزمة معاملات سعودية منفذة مستقلة وحقيقية مؤرخة وموثقة ورخص استخدام تسمح بالتحقق والاشتقاق.
2. خبير التقييم: بروتوكول مراجعة مسجل قبل فتح مجموعة الاختبار مع قائمة مطابقة للأصل والنوع والمنطقة والحقوق والأفق الزمني وأسعار البيع الفعلية.
3. فاحص إحصائي مستقل: توزيع متوازن حسب الرياض وجدة والشرقية والقطاعات والقيم ونطاقات التواريخ، وحساب MAE/MAPE وMedian APE وP90 والاتجاه ومقارنة معيار مرجعي، مع حجم عينة وبرهان ثقة محدد مسبقًا.
4. مالك المنتج: ربط التقرير الحقيقي بالبوابة وحفظ الأدلة وصحة مصادرها وربطها بالإصدار SHA، وإجراء UAT بشري على حالات نجاح وفشل وتعارض.
5. المخوّل النظامي: اعتماد صلاحيات الاستخدام المهني واتخاذ القرار والنشر منفصلة عن النجاح التقني.
