# RIAI-02A — Acquisition Basis

## Scope

This wave reconciles three distinct bases for a Residential Income acquisition:

- Price-only basis.
- All-in acquisition basis.
- Initial equity basis.

The all-in basis is:

`Purchase Price + Transaction Costs + Complete Immediate CAPEX + Initial Tenant Improvements + Initial Leasing Costs + Initial Reserves`

The initial equity basis is:

`All-in Acquisition Basis - Initial Debt Proceeds`

## Required adopted inputs

- Purchase price.
- Transaction costs.
- Initial tenant improvements.
- Initial leasing costs.
- Initial reserves.
- Initial debt proceeds, including an explicit zero when the case is unlevered.
- A complete immediate-CAPEX assessment from RIAI-01C.

Every transaction input uses `SAR`, is independently evidence-aware, and must be adopted for underwriting. Missing components are not inferred as zero. Initial debt cannot exceed the all-in acquisition basis.

## Boundaries

Purchase price remains an input and is not presented as calculated value or maximum justified price. The result does not calculate value, returns, financing approval, a legal conclusion, an investment decision, or transaction authorization.
