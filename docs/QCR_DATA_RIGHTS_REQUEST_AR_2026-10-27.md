# مسودة طلب حقوق البيانات والتكامل — ستارتك العقارية
**الحالة:** مسودة جاهزة للمراجعة والإرسال من المالك أو الممثل النظامي؛ **لم ترسل ولم يصدر تصريح.**
**الجهة المستهدفة:** الهيئة العامة للعقار / الجهة المالكة للبيانات / المزوّد المرخّص بحسب اختصاص البيانات.
**مرجع التنفيذ:** Q01 / G02 / G10 / N03 — برنامج #747

## الموضوع: الاستفسار عن إتاحة بيانات الصفقات العقارية المنفذة وشروط استخدامها في التحليل الاستثماري
السلام عليكم ورحمة الله وبركاته،
نعمل على تأهيل منصة «ستارتك العقارية» للتحليل الاستثماري ودراسة الجدوى العقارية داخل المملكة. ونرغب في معرفة القنوات المتاحة نظاميًا للوصول إلى بيانات **الصفقات العقارية المنفذة** على مستوى العقار والمدينة ونوع الاستخدام، مع التمييز الواضح بينها وبين العروض والأسعار الاسترشادية.

نأمل إفادتنا كتابيًا بالتالي:
1. الجهة المالكة/المسؤولة عن البيانات ونقطة اتصال منح الحقوق، وهل توجد واجهة API أو ملفات مرخصة أو خدمة تعاقدية.
2. حدود الاستخدام المسموح لأغراض التحليل الداخلي، وإصدار التقارير للعملاء، والعرض العام، وإعادة الاستخدام والاشتقاق التجاري، مع تسعير كل نطاق إن وجد.
3. الحقول المرخصة لكل صفقة: مرجع العملية، تاريخ التنفيذ، المدينة والحي، تصنيف العقار، نوع الحق، المساحة والقيمة الإجمالية والعملة، ومستوى إحداثيات الموقع والدقة التاريخية.
4. سياسة التحديث والتأخير وإلغاء/تصحيح الصفقة، وحدود القياس الدقيق، والتوثيق اللازم للتحقق من السجلات وتفادي التكرار.
5. متطلبات أمن البيانات، ومدة التخزين والاحتفاظ والحذف، والبيانات الشخصية التي يجب استبعادها أو إخفاؤها.
6. نطاق التجربة الفنية المسموح به قبل إطلاق الاستخدام التجاري، والاتفاقيات أو الرسوم أو الموافقات المطلوبة.

يرجى تزويدنا بمسودة الشروط أو الإحالة إلى الجهة المختصة. لن نبدأ جمع بيانات آلي أو إعادة توزيعها تجاريًا قبل ثبوت الإذن المناسب.

مع التحية،
المالك/المفوّض — مشروع ستارتك العقارية

## بوابة قبول البيانات
لا يغلق Q01 قبل حفظ **وثيقة الحقوق الأصلية** والتحقق من صحتها وتحديد مدة صلاحيتها، واختبار قناة المزوّد عبر حساب مصرح، وربط العينة بسجل المصدر والتاريخ ومرجع الصفقة. الرد العام أو رابط البحث المفتوح لا يساوي إذن API أو ترخيصًا تجاريًا.
