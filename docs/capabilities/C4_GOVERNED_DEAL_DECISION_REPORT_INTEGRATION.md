# C4 — Governed Deal Decision & Report Integration

## Status

Draft integration layer. No merge, deploy, production activation, transaction authority, certified valuation authority, or public-AI authority is established by C4.

## Qualified dependency

C4 is stacked on the qualified integration branch:

- branch: `c3i-c2s-governed-reconciliation-integration`
- dependency head at C4 creation: `e0bf23d45ffc32c87a0e1353b2bc63d8d2553421`

C4 adds no valuation mathematics. It consumes a governed C3 reconciliation result and binds it to a deal/case workflow.

## Governance flow

`C1 official geospatial evidence -> C2/C2S governed market/source evidence -> C3M + income/cost method indications -> C3 governed reconciliation -> C4 deal snapshot -> human reviewer recommendation -> non-authorizing governed report`

C4 deliberately separates:

1. analytical valuation indication,
2. governed reconciliation,
3. human reviewer recommendation,
4. approval authority,
5. transaction authority.

A reviewer recommendation never becomes approval by inference.

## Fail-closed controls

C4 rejects the integration when any of the following occurs:

- C3 schema/status is not qualified and `READY`;
- `decisionReady !== true`;
- reconciliation blockers exist;
- valuation scope is not `WHOLE_PROPERTY`;
- property or valuation-date binding mismatches;
- reconciliation is stale under the explicitly supplied freshness policy;
- C1/C2 dependency status is not `READY`;
- upstream final/certified valuation, transaction authority, or public-AI authority is asserted;
- analytical value indication is absent/invalid;
- method lineage is incomplete;
- C3 result hash cannot be deterministically reproduced;
- evidence/reconciliation/method source hashes do not bind correctly;
- a human review attempts to inject approval or transaction authority;
- a persisted snapshot is changed without a matching deterministic snapshot hash;
- report lineage is incomplete or the snapshot is no longer valid.

## Saved-deal persistence

`src/app/valuation-saved-deal-bridge.js` persists `governedDealDecision` only for building-mode records and re-validates the snapshot on both write and reload. Persistence cannot upgrade a recommendation into approval or transaction authority.

## Human review semantics

Allowed reviewer recommendations are:

- `CONTINUE_DUE_DILIGENCE`
- `REQUEST_MODIFICATION`
- `HOLD_FOR_EVIDENCE`
- `DO_NOT_ADVANCE`

These are review recommendations only. They are not BUY/SELL/INVEST/APPROVE instructions and do not establish approval authority.

## Governed report

A report generated by C4 is always classified:

`NON_AUTHORIZING_ANALYTICAL_OUTPUT`

Mandatory disclosures state that the report:

- is not a final or certified valuation;
- requires a human decision and separate approval authority;
- does not convert a reviewer recommendation into approval;
- has `TRANSACTION_AUTHORITY = FALSE`;
- has `COMMERCIAL_GO_LIVE = HOLD`.

## Authority boundary

C4 fixes the following authority state in snapshots and reports:

- `commercialGoLive: HOLD`
- `transactionAuthority: false`
- `publicAi: false`
- `canonicalBaselineActivationAuthorized: false`
- `approvalAuthorized: false`
- `finalValuationConclusionEstablished: false`
- `certifiedValuationEstablished: false`
