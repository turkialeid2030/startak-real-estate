# توصيل طبقة سلامة الدراسة الشخصية بالواجهة — 24 أكتوبر 2026

## النطاق المنفذ
- ربط `PersonalResearchReadinessPanel` مباشرة بمدخلات الدراسة الحالية، النتيجة المحسوبة، ونوع العقار (مبنى أو أرض)، وإشارات خطأ الإدخال.
- عرض الحالات: حجب الحساب غير المكتمل أو الذي أخفق في مطابقة المجاميع والتدفقات؛ تحذير عند وجود قيود مالية فاشلة؛ تحقق حسابي مبدئي ناجح عند مطابقة الحسابات المطلوبة.
- عرض أسباب الحجب والتحذير، والتنبيه إلى أن اللوحات الأقدم قد تحتفظ بآخر حساب صحيح إذا أصبح الإدخال الجديد غير صالح.
- إظهار حالة المدخلات والنتيجة قبل شريط المؤشرات، وباللغتين العربية والإنجليزية، مع دعم `aria-live`.
- لا تعدل هذه الطبقة أسعار العقار، أو IRR/NPV، أو التدفقات والتكاليف، أو مسار الحفظ والتصدير الحالي.

## قيد مهم
التحقق من تطابق مجموع التكلفة وصافي الدخل والتدفقات داخل النموذج لا يثبت أصالة صفقات السوق أو دقة الافتراضات أو موثوقية بيانات المقارنات. الاستعمال الشخصي لا يغير ضرورة حماية الوثائق، ولا يعني أن رابط الموقع العام خاص.

## المتبقي
ربط هذا التحقق بمنع تصدير التقرير الذي يتضمن مدخلات غير صالحة، مع عدم حجب حفظ مشروع مسودة غير مكتمل. واختبار تدفق المستخدم الفعلي على النسخة المنشورة، وتوثيق استعادة البيانات وتطابق ملف الحزمة وشيفرة الإنتاج SHA، وتأهيل مصادر السوق والعقارات المتخصصة ببيانات حقيقية.

## معايير التنفيذ
اختبارات الوحدة `tests/defects/personal_research_readiness.js`، واختبار التوصيل `tests/defects/personal_research_ui_contract.js` ضمن Release Verify؛ بالإضافة إلى اختبار المتصفح الشامل والمراجعة على رأس PR المحدد. تبقى نتيجة السوق والترخيص والتفويض المالي غير مؤهلة تلقائيًا.
