# ستارتك العقارية — حزمة التنفيذ الموحدة للتأهيل والجاهزية التجارية
**مرجع البرنامج:** STARTAK-QCR-2026-10-27  
**تاريخ الأساس:** 27 أكتوبر 2026  
**مدة مستهدفة وليست وعدًا بالإغلاق:** 90 يومًا؛ مراجعة قرار مستهدفة 25 يناير 2027  
**الحالة الحالية:** `HOLD / NOT_AUTHORIZED` للخدمات التجارية والمهنية والذكاء الاصطناعي العام.  
**قاعدة أساسية:** نجاح نشر الواجهة البحثية لا ينشئ حقًا في استخدام بيانات رسمية تجاريًا أو إصدار تقرير تقييم مرخص.

## ما بدأ تنفيذه
1. تثبيت سجل واحد قابل للفحص: `governance/qualification-90-day-program-20261027.json` ويغطي كل الفجوات G01–G14 ويربط N03/N04/N05/N06/N07/N08/N09/N10/N11/N12.
2. تعيين **الأدوار المسؤولة** وليس تسمية أشخاص غير معينين. `assignedPerson=null` حتى وجود تكليف فعلي.
3. تثبيت نطاق أول تجربة تجارية محتملة: الرياض / الأراضي، المباني السكنية المدرة للدخل، والعقارات التجارية المدرة للدخل. جدة والمنطقة الشرقية توسع مشروط بتوفر الأدلة والترخيص.
4. وضع متطلبات الأدلة والقبول لكل مسار في سجل موحد مع فحص آلي لا يحوّل اسم المستند أو تجزئته إلى موافقة.
5. حظر الميزانية والتسعير المُختلقين: `approvedBudgetSar=null` إلى اعتماد مالي فعلي.

## تعليمات إصدار طلبات العمل دفعة واحدة
- **البيانات:** اطلب من الجهة المالكة بيان الترخيص المسموح، القنوات الرسمية، مستوى السجل، حق العرض وإعادة الاستخدام، التحديثات وشروط الاحتفاظ، من دون استخراج آلي حتى تثبت الأذونات.
- **التقييم:** اطلب من مراجع مؤهل خطة اختبار مغلقة قبل الاطلاع على النتائج، مع عينات صفقات منفذة ومصادرها، والتقسيم بالمدينة والنوع، وMedian APE وP90 والانحياز والتغطية. **حدود الدقة تُعتمد مسبقًا** ولا تُختلق.
- **الأمن:** نطاق فحص OIDC/RBAC/RLS وخزنة الوثائق والتشفير والاستعادة والنسخ والاحتفاظ والإبلاغ. اختبار خارجي مستقل بلا ثغرات حرجة أو عالية معلقة قبل التصريح.
- **القانون:** تحقق من لائحة الاستشارات والتحليلات العقارية ورخصة فال بحسب نشاط الخدمات، ومن اختصاص مهنة التقييم ورخص المقيم، ومن قواعد PDPL بحسب حقيقة البيانات والمعالجة (ومنها دراسة إلزام تعيين مسؤول حماية البيانات).
- **الذكاء الاصطناعي:** تفعيل مخول في بيئة معزولة بعد عقد المزود والميزانية وقياس فعلي للاستهلاك، بمحتوى اختبار غير شخصي؛ لا قرار استثماري آلي.
- **العملاء:** تجربة استطلاعية غير ملزمة ضمن الوضع المسموح، دون تخزين بيانات عميل حقيقية أو إصدار تقرير مهني دون الموافقات اللازمة.

## مؤشرات المتابعة الأسبوعية
- عدد مسارات `HOLD_EVIDENCE_INCOMPLETE` وعدد المستندات ذات وصف مصدر/تجزئة مقبول **وغير متحقق مستقلًا**.
- نسبة المسارات التي لها **شخص مكلّف رسميًا**، وخط أساس الميزانية المعتمد ومصروفات فعلية مقابل خطة.
- اكتمال تغطية مصادر الصفقات: 100% من المقارنات المسموح باستخدامها في التقرير لها مصدر وحقوق مثبتة (هدف مستقبلي).
- مؤشرات دقة محرك التقييم على حالات مستقلة *بعد* تحديد سياسات القبول المسبقة من مختص مستقل.
- زمن إعداد دراسة الاستثمار والتكلفة لكل دراسة، مع عينة وتجربة مضبوطة، ومؤشرات استعداد الدفع.
- صفر قرارات/تقارير معتمدة دون تفويض، وصفر نتائج اختراق حرجة/عالية غير معالجة عند إقرار الإطلاق.

## تسجيل الأدلة دون إفشاء
نفّذ محليًا: `node tools/qualification-program-report.js`. الوضع الحالي بلا ملفات دليل يعيد HOLD مع قائمة المطلوب.

عند وجود **بيانات وصفية غير حساسة فقط**: `node tools/qualification-program-report.js --evidence=/absolute/private/path/metadata.json`.
شكل الإدخال الاختياري: 
```json
{
 "Q01:dataRightsAgreement": {
   "artifactRef": "internal-vault:contract-identifier",
   "sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
   "observedDate": "2026-10-27"
 }
}
```
هذا مثال اصطناعي **لا يمثل عقدًا حقيقيًا**. لا ترفع الوثائق السرية أو تفاصيل العملاء أو رموز الوصول إلى GitHub. حتى مع وصف مكتمل لكل الأدلة، المخرجات `EXTERNAL_INDEPENDENT_REVIEW_REQUIRED` ولا تُنشئ موافقة.
