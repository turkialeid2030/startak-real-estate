## Actual implementation
- C70 nine reference controls remain the prerequisite: a document can be fingerprinted only after a user saves the matching reference ID for that exact specialist case and evidence type.
- Actual browser `<input type="file">` accepts locally selected PDF, PNG or JPEG up to **5 MiB**. The file size is checked before loading, and a small leading-byte signature must match the declared media type. Real `File.arrayBuffer()` reads its bytes and browser `crypto.subtle.digest('SHA-256', bytes)` hashes them. Filename and file content are never sent to an API or saved in the local Saved Deal.
- One strict saved `institutionalEvidence.specialistDocumentManifest` record contains only per-C61 evidence reference ID, category, lowercase SHA-256, byte count and MIME type; the file itself **is not uploaded** and **cannot be re-downloaded** from this record. Manifest also binds to specific hotel/industrial classification, subtype, property ID and dated C70 inventory. Any change to a scoped reference causes an invalid manifest, not automated trust migration. Explicit clear control allows the user to delete old manifest metadata while preserving reference IDs.
- Validation refuses arbitrary fields, forged source-verification flags, duplicate control types, cross-property records, unsupported media types, over-5MiB files and header-versus-MIME mismatches. A syntactically valid SHA stored by an actor is **still not independent evidence** that the original file was hashed on a trusted device. SHA alone proves neither authorship nor document authenticity.

## Explicit limits — remains OPEN
- **No genuine user's source documents** were obtained in this test: PDF bytes are intentionally synthetic. The header magic check does not parse PDF pages, validate the whole file, detect malware, or prove a signature. Local hash has not been cryptographically witnessed by a trusted third party.
- No external Saudi authority, executed comparable, title validation, evidence ownership/rights, legally acceptable reviewer identity/license, storage and access-control service for real customer documents, specialized appraiser, human UAT or certified property value/report. A production-grade file-ingestion architecture needs authenticated server upload, malware scanning, encrypted evidence vault, auditable chain of custody, signed verification, redaction, retention/PDPL policy, controlled source-right proofs and external professional review.
