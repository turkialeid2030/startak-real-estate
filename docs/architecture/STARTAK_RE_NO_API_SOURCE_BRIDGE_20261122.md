# ستارتك العقارية — جسر ربط المصادر دون API

**تاريخ القرار:** 22 نوفمبر 2026 | **نطاق التنفيذ:** فرع تطوير خاص بالبحث العقاري، وليس نسخة الإنتاج. **حالة التكامل الآلي:** غير مفعل.

## 1. القرار الفني

نمط `Owner-mediated research bridge` على مسارين منفصلين، بلا API ولا كاشط مواقع ولا ملحق متصفح يقرأ جلسات الدخول:

1. **مراجع المواقع:** يفتح الباحث الموقع من ستارتك بنفسه، ويسجل رابطًا آمنًا وتاريخ الاطلاع والمدينة/الحي اختياريًا. يخزنها المكوّن في جلسة المتصفح للبحث فقط، ثم يتيح تنزيل ملف JSON محلي مقيّد وبسيط واستعادته لاحقًا. لا تنقل أرقام أو صفقات أو بيانات ملاك أو كلمة مرور من الموقع، ولا يتجاوز قيود المصدر.
2. **ملفات الجهات المرخصة:** يحمل المستخدم من الجهة الأصلية مجموعة بيانات ذات ترخيص يسمح بالاستخدام المقصود، ثم يرفع ملف CSV في استيراد البيانات البحثية **الموجود مسبقًا** في `SaudiNationalIntelligenceSourcesPanel`. عند تقديم XLSX من موقع رسمي، يُحوّله محليًا إلى CSV مطابق للقالب قبل الاستيراد؛ **لا تدعي هذه النسخة أنها تستورد XLSX مباشرة**. يستمر `importNationalSourcesCsv` في رفض المدخلات غير المتجانسة والتواريخ والوحدات/الأنواع غير الصحيحة، وإبقاء `marketValuationEligible=false`.

يقوم `src/components/NoApiSourceBridgePanel.jsx` بتقديم روابط 35 مصدرًا تغطي المواقع السابقة والبوابات الموثقة؛ `src/market/no-api-source-bridge.js` يسجّل كل رابط كـ `RESEARCH_REFERENCE_ONLY` لا يملك أي سلطة مالية أو نظامية. تُعرض الوحدة داخل لوحة «مصادر البيانات الرسمية والتقييم العقاري» المتاحة من شاشة موقع/دراسة العقار.

## 2. رحلة استخدام الباحث

1. حدد المصدر (مثل وزارة العدل أو الخرائط الحضرية أو سهيل أو أرض).
2. اضغط **فتح الموقع الأصلي**. يجري أي دخول أو بحث بالمتصفح وبصلاحيات المستخدم، ولا ينتقل رمز الدخول إلى ستارتك.
3. احتفظ بنتيجة المراجعة في المصدر. في ستارتك سجل **الرابط فقط** مع تاريخ الاطلاع والموقع العام إن لزم. النظام يحذف سلسلة الاستعلام و`hash` من الرابط المسجل لحماية معلمات الجلسات والبيانات الشخصية.
4. اضغط **إضافة مرجع بحثي**؛ الحالة تبقى غير متحققة وغير مرخصة آليًا. زر تنزيل سجل المراجع ينتج JSON محليًا يمكن استعادته في جلسة أخرى. لا يوجد طلب HTTP جديد لأي موقع خارجي أو تخزين متصفح دائم لروابط البحث.
5. إذا كان المصدر يقدم **ملف بيانات يحق إعادة استخدامه** بصورة موثقة: نزّل الملف من الجهة، وراجع الرخصة والإسناد، ثم استورده من خانة CSV البحثية الموجودة بجوار الجسر. النظام لا يرقّي هذا الملف إلى قيمة أو صفقة منفذة معتمدة من تلقاء نفسه.
6. قبل الاستخدام في التقييم، قدّم دليل حق استعمال البيانات، وأصل الصفقات/الإيجارات أو الوثائق، والهوية العقارية والتاريخ، وأرسل المادة إلى مراجع مؤهل في مسار الحوكمة.

## 3. قيود مصادر محددة

| المصادر | المعالجة |
|---|---|
| REGA مؤشرات وصفقات/إيجارات | فتح رابط وتوثيق مرجع فقط؛ [شروط الموقع](https://rei.rega.gov.sa/ar/terms-and-conditions) تقيد النسخ والاشتقاق والتوزيع دون موافقة الهيئة الخطية |
| وزارة العدل | [سياسة البيانات المفتوحة](https://www.moj.gov.sa/ar/OpenData/Pages/OpenDataPolicy.aspx) تتيح تنزيل بعض المعلومات بصيغة Excel؛ التأكد من رخصة **مجموعة البيانات** المحددة قبل تحويل/استيراد CSV |
| UMAPS / بلدي | استخدام يدوي في الخرائط والمخططات والاستعمالات؛ لا API معتمد ولا رخصة إعادة استعمال طبقات مثبتة؛ لا إثبات آلي للصك أو صلاحية البناء |
| RER / إيجار | مراجع يدوية/معاملات مصرح بها فقط؛ لا تخزين كلمات مرور أو ربط جلسات موحد إلى ستارتك |
| سهيل / أرض / بسيطة / GREM / بيوت / تثمين | روابط بحث وتقديرات استرشادية؛ شروط حقوق العرض والنسخ مستقلة عن إمكان قراءة الموقع. لا استخراج آلي أو نسخ محتوى محمي |
| المقيمون / معايير IVS / التفتيش الفني | مراجع مهنية لا أرقام بيع منفذة؛ التقارير تحتاج ترخيص مقيم/حقوق استعمال وملف مهمة وتاريخ قيمة |

## 4. موانع التحويل إلى مرجع معتمد

`captureReference` يفرض HTTPS ونطاقًا مسجلًا بعينه ومنفذ TLS افتراضيًا ودون بيانات مستخدم/كلمة مرور في العنوان، ويزيل الاستعلام والجزء المقطعي من الرابط المسجل. تاريخ الاطلاع لا يمكن أن يكون مستقبلًا. كل مرجع يحتوي:
`evidenceClass=RESEARCH_REFERENCE_ONLY`, `sourceAuthenticated=false`,
`licenseVerified=false`, `propertyIdentityVerified=false`,
`decisionReady=false`, `professionalReportAuthorized=false`,
`valuationSar=null`, `annualRentSar=null`.

لا يمكن تغيير هذه العلامات عبر ملف مستورد: JSON مسموح فقط بحقول `sourceId,sourceUrl,city,district,observedOn` مع رقم صيغة ثابت، حجم 64 كيلوبايت وحد 100 مرجع. يرفض الاستيراد حقول السلطة/قيم العقارات، وتُعاد جميع العلامات إلى الحالة غير المخولة. الملفات محلية بمبادرة المستخدم؛ لا طلبات شبكة أو آلية مجدولة ولا نقل بيانات خاص إلى الطرف الثالث.

## 5. لماذا ليس هناك «تزامن تلقائي»؟

- دون API أو ملف عام ذي ترخيص، لا توجد وسيلة عامة مضمونة قانونيًا وتقنيًا لاستخراج بيانات المواقع المحمية بصورة دورية أو استعادة جلسات الدخول بلا موافقة الجهة.
- يمكن **عند الحصول على اتفاقية مكتوبة** بناء موصل بديل يتلقى ملفات CSV دورية عبر واجهة رفع المستخدم أو مجلد ملفات مصرح به، مع ETL وفحص هوية البيانات والنسخ والتكرار. هذا مشروع مستقل يتطلب حفظ أسرار وصلاحيات وتدقيق امتثال.
- يمكن توفير أتمتة متصفح بإشراف المستخدم فقط في الحالات التي تسمح شروط المصدر فيها بهذا النوع من الاستخدام، دون تجاوز CAPTCHA أو الحظر أو نسخ حسابات المستخدمين؛ لم تُنفذ في هذه النسخة.

## 6. RACI والقبول

| المهمة | المنفذ R | المعتمد A | معيار القبول |
|---|---|---|---|
| اختبار رابط المصدر وبياناته | محلل البيانات / مطور واجهة | قائد المنتج | 22 مصدرًا وروابط HTTPS مع قائمة نطاقات ثابتة |
| قبول ملف بيانات مفتوحة | مسؤول المصادر والامتثال | مالك البيانات/المسؤول القانوني | نسخة رخصة وبيان الإسناد ومجموعة بيانات وتاريخ محددان |
| استيراد CSV دون ادعاءات | QA ومهندس بيانات | مدير التقنية | حالات سلبية وسليمة، جميع المخرجات البحثية غير معتمدة |
| تحقق بيانات القطعة والحق | متخصص GIS ومقيم | مدير التقييم المهني | مستندات ومصادر مستقلة وتاريخ وحدود ونطاق استخدام |
| التحقق من حماية البيانات | أمن المعلومات / DPO | مسؤول الامتثال | منع URL userinfo/port، منع سجلات سلطة مستوردة، عدم تسريب بيانات شخصية |
| النشر التجاري | مدير الإطلاق والحوكمة | السلطة المخولة | Q01–Q12 وUAT حقيقي وحقوق البيانات وGO كتابي |

**المؤشرات:** عدد الروابط الصحيحة، مصادر بترخيص موثق، معدلات رفض الإدخال الخاطئ، نسبة المراجع التي تمت مراجعتها مهنيًا، بيانات معتمدة دون دليل = **صفر**، وزمن التحديث المحلي. لا تدعي الوثيقة تحقيق مؤشرات السوق أو دقة تقييم قبل التشغيل الحقيقي.

**قرار الإصدار:** `GO` للبحث والتطوير المحلي، `HOLD_NOT_AUTHORIZED` للاعتماد المهني والنشر التجاري وموصلات سحب المواقع.

## 7. تحسين مسار وزارة العدل المفتوح الموجود مسبقًا

لا يبدأ الربط من الصفر: الوحدة `src/market/saudi-open-data-research.js` في STARTAK كانت تقرأ **عند طلب المستخدم فقط** ملفات CSV فصلية عامة لمنظومة بيانات وزارة العدل (2025-Q3 و2025-Q4 و2026-Q1) من مستودع بحثي، وتوفر متوسط/وسيط أسعار على مستوى الحي **كسياق فقط** دون تقرير قيمة معتمد أو إثبات نوع الأصل.

كشف تدقيق هذه الجولة ثغرة مباشرة في هذا المسار دون API: `asNumber` كان يمحو كل الفواصل والمسافات ويحوّل النص المعيب `1,2` إلى `12`. استُبدل بالمحلل المالي الموحد `parseNumericText`، مع حالات اختبار رفض قيمة بيع ومساحة مشوهتين وقبول أرقام عربية ذات فواصل سليمة. لا تتحول البيانات المفتوحة بهذا الإصلاح إلى مصادر فردية متطابقة أو موثقة للصك، ولا تُعد أحدث من الربع المنشور.

**قيد الترخيص:** كون الملفات مذكورة بوصفها بيانات مفتوحة في مسار بحثي لا يعفي مالك التشغيل من إثبات نسخة الرخصة والإسناد وحقوق استضافة نسخة كل ملف. ولا يُفترض أن مستودع طرف ثالث جهة إصدار الصفقة أو مزود API مرخص.
