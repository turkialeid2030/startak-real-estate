# STARTAK العقارية — محرك تأهيل الأدلة قبل احتساب القيمة

**التاريخ:** 22 نوفمبر 2026. **التنفيذ:** فرع تطوير مسودة مستقل بعد جسر المصادر اليدوي #817. **الاعتماد التجاري:** `HOLD_NOT_AUTHORIZED`.

## 1. تعريف المشكلة

توفر المواقع الحكومية والخاصة مصادر متفاوتة: صفقات منشورة، إحصاءات مجمعة، عقود إيجار مؤشَّرة، عروض أسعار، بيانات تنظيمية، تقديرات آلية خارجية، وروابط الاطلاع اليدوي. جمعها في جدول واحد أو امتلاك رابط لموقع حكومي **لا يجعلها** معاملات منفذة معتمدة أو بيانات مرخصة لإعادة الاستخدام أو مقارنات صالحة لقيمة عقار بعينه.

## 2. ما نُفّذ فعليًا

- `src/market/evidence-qualification-gate.js`: محرك حتمي، لا يستدعي مواقع ولا واجهات API ولا يغير محركات الحساب. يستقبل ملفات/سجلات البحث الوطني المراجَعة نحويًا (`importNationalSourcesCsv` أو مسار Kite البحثي) وروابط الجسر اليدوي، ويفحص:
  - معرّف المصدر والفئة الصحيحة (`OFFICIAL_REPORTED_SALE / THIRD_PARTY_REPORTED_SALE / *AGGREGATE / EXTERNAL_AVM_ESTIMATE / RESEARCH_NOTE`)؛
  - تطابق نطاق URL رسمي محدد، اتصال HTTPS، حظر userinfo والمنفذ المخصص والنطاقات المقلدة؛
  - هوية المنطقة/الحي والنوع مقارنة بموضوع الدراسة (قد يكون تطابق حي، **وليس** إثباتًا لذات القطعة)؛
  - تواريخ الاطلاع والصفقة/الفترة، القيم الرقمية غير المنطقية، ومعرف الصفقة المنشورة؛
  - تعارض أو تكرار المعرّف نفسه داخل المصدر أو عبر مزودين على أساس الموقع والتاريخ والمرجع (اشتباه للمراجعة، لا دمج تلقائي)؛
  - ادعاءات زائفة لحق الوصول/الاعتماد أو أن الصفقة موثقة/القيمة صالحة في حمولة استيراد.
- `src/components/EvidenceQualificationReviewPanel.jsx`: لوحة عربية/إنجليزية في نفس شاشة مصادر الدراسة العقارية تعرض عدد السجلات، الروابط اليدوية، المرشحات المبدئية للبيع، المتوسطات، تقديرات النماذج الخارجية، المكررات والمرفوضات وأسباب التعليق. يوجد زر تنزيل ملف مراجعة JSON محلي.
- `NoApiSourceBridgePanel.jsx` يبلغ لوحة التأهيل عن تغيّر مراجع الروابط اليدوية؛ `SaudiNationalIntelligenceSourcesPanel.jsx` تمرر السجلات البحثية؛ `PropertyMarketLocationPanel.jsx` يمرر المدينة والحي ونوع العقار الجاري دراسته. لا يوجد اعتماد تلقائي ولا اتصال مباشر إلى القيم المالية.
- `tests/defects/evidence_qualification_gate.js`: حالات اصطناعية سليمة وسلبية للمصدر، URL، تزوير حالة تحقق، التكرار عبر REGA/MOJ، اختلاف المدينة/الحي ونوع العقار، البيانات الإحصائية والنموذج الخارجي، ملف المراجعة والتوصيل في واجهة المستخدم.

## 3. مصفوفة الفصل بين الاستخدامات

| نوع السجل | نتيجة المحرك | مسار الترقية الخارجي المطلوب |
|---|---|---|
| رابط موقع أو خريطة | `MANUAL_REFERENCE / HOLD_REVIEW` | توثيق صفحة المصدر وتاريخ الاطلاع وهوية القطعة وحق الاستخدام |
| مؤشر رسمي أو خاص مجمع | `AGGREGATE_CONTEXT / HOLD_REVIEW` | تعريف المدينة/الحي والفترة ووحدة المتوسط وبيان حدود العينة؛ يبقى مرجع سياق |
| صفقة منشورة لدى مصدر | `REPORTED_SALE_CANDIDATE / HOLD_REVIEW` | أصل المعاملة، رقمها، تاريخها، الحق والمساحة ونوع الأصل، إزالة التكرار، ترخيص البيانات ومراجعة مؤهلة |
| تقدير آلي خارجي | `EXTERNAL_MODEL_BENCHMARK / HOLD_REVIEW` | حفظ اسم/إصدار النموذج وتاريخ التقدير ودقة مستقلة خارج العينة؛ ليس بيعًا منفذًا |
| ملاحظات بحثية | `RESEARCH_NOTE_ONLY / HOLD_REVIEW` | توثيق المرجع؛ لا تسعير رقمي |
| URL غير آمن أو ادعاء اعتماد مزور | `REJECTED` | تصحيح الملف والهوية؛ يمنع إدخاله كدليل |

**حقيقة برمجية:** `certifiedMarketValueSar=null` و`certifiedMarketRentSar=null` و`marketValuationEligible=false` لجميع الحالات مهما كانت التسمية التي قدمها الملف. `professionalReportAuthorized=false` و`productionDataConnectorEnabled=false`. لا يحق لحقل `sourceRecordAuthenticated=true` المستورد أن يشهد لنفسه.

## 4. كيف تُنتج قيمة صحيحة مستقبلًا؟

1. **اكتساب البيانات باحترام الترخيص:** ملف رسمي متاح بموجب رخصة منشورة تغطي الاستخدام أو اتفاقية مزود خاصة. لا كاشط يحاكي API ولا تجاوز مصادقة.
2. **هوية الأصل:** ربط موثق بين مدخلات الدراسة وقطعة/صك/مخطط وحقوق وقيود محددة، وأسـاس المساحة (Land/GFA/NLA/GLA) والحقوق وقت التصرف.
3. **منهج المقارنات:** معاملات مماثلة فعلًا، مع ضبط التاريخ والمسافة والصفة والتصنيف وحقوق الطرفين والتعديل؛ الإعلان والسعر المطلوب يبقيان فئة مختلفة، كما يبقى المؤشر المجمّع دون صفة صفقة.
4. **منهج الدخل:** الإيجار القانوني الحالي مقابل السوق الجديد، سجلات عقود ملائمة، المصاريف، الإشغال، معدل رسملة مستقل وقابل للتدقيق، الفنادق والتخصصات على محرك القطاع.
5. **المراجعة البشرية المستقلة:** تعيين مقيم مرخص ومراجع حقوق بيانات ومسؤول أمن، واعتماد أدلة كل صفقة، دون جعل صاحب الملف يحدد وحده العلم `VERIFIED`.
6. **المعايرة:** 17+4 حالة خاصة على المحرك الحقيقي وفي نطاقها، وعينة سعودية خارج بناء النموذج لتسجيل MAE/MAPE والتغطية بحسب نوع الأصل والمدينة، وإظهار عدم اليقين.

**لم تُنفذ هذه المرحلة النهائية لأن أدلة الترخيص وأصول الصفقات والعينة الخاصة والتوقيعات والصلاحيات المستقلة غير متاحة للمحرك.** أي زر «اعتماد» لا يرفع حالة الجاهزية حتى اكتمال مسار مراجعة حوكمي حقيقي مستقل.

## 5. ملف المراجع والحماية

`portableReviewDossier()` يصدر محليًا ملخصًا للفئات وأسباب الاستبعاد وعدد المصدر والمراجعات ومفاتيح التعارض فقط؛ **لا ينسخ أسعار الصفقات أو هويات ملاك العقارات أو روابط الجلسات**. هذه مادة تجهيز للفحص البشري وليست ملفًا موقعًا أو شهادة ترخيص. يرفض التصدير إذا زاد حجمه عن 256 كيلوبايت؛ حد الإدخال 1500 صف بحثي و100 مرجع.
