## Purpose

Record public-source prequalification signals for RFP targeting. This matrix does **not** select, engage, credential-approve or accept any provider. Final appointment still requires proposal review, named reviewer verification, conflict/independence checks, scope acceptance, commercial approval and the vendor scorecard.
