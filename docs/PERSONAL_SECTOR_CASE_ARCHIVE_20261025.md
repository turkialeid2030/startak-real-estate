# ستارتك — حفظ واستعادة سيناريوات جميع القطاعات — 25 أكتوبر 2026

## ما تم
إضافة أداة تصدير/استيراد من داخل مختبر الطرق الثلاثة المعتمد للدراسات الشخصية، لجميع الفئات العقارية الثلاث عشرة.
- تصدير **مدخلات الدراسة فقط** (الموقع ونوع العقار والحقوق، الدخل والتكاليف، الصفقات المدخلة، أوزان الطرق)، إلى JSON محلي من متصفح المالك.
- بصمة SHA-256 محسوبة محليًا باستخدام WebCrypto، مع رقم إصدار `PERSONAL_SECTOR_CASE_ARCHIVE_V1` وتاريخ إنشاء بنمط UTC.
- استيراد محلي مشروط: حد 64KiB وفك UTF-8 الصارم، تطابق الإصدار والحقول وأنواعها وأطوالها وبصمة الملف، ومطابقة صنف العقار المختار. إلغاء الاستيراد عند التعارض؛ **عدم تعديل الدراسة الحالية عند الفشل**.
- استعادة المدخلات الأصلية فقط وإلغاء كل نتيجة سابقة `setOutput(null)`؛ يلزم الضغط مجددًا على زر الحساب. لا تحفظ الأداة القيمة المرجحة، أو حالة اعتماد، أو صلاحية إجراء شراء.
- لا رفع للملفات إلى خادم ستارتك، ولا حفظ للمدخلات في ذاكرة موقع دائمة عبر هذه الإضافة.

## قيود جوهرية
SHA-256 يتحقق من سلامة ملف ضد التعديل غير المتوافق مع بصمته ولكنه **ليس توقيعًا رقميا** ولا يُثبت الهوية أو أصالة الصفقة: يمكن لجهة تبدل الملف إعادة احتساب البصمة. احفظ الملف في مكان آمن؛ فهو يحتوي على بيانات عقارية تجارية يمكن اعتبارها حساسة.
هذا المسار ليس مزامنة تلقائية بين الأجهزة ولا يربط المدخلات بعد بمنظومة العقود أو المحاسبة أو التقرير المهني الحاكم. تجارب الأداء المحلية والمتصفح مهمة قبل إطلاق أي مزامنة أو تسجيل دخول سحابي. لا يُعدل المحرك المالي الأصلي ولا يستنتج اعتمادًا مهنيًا أو تجاريًا.

## أدلة اختبار مطلوبة
- تدوير ملف مرجعي لفندق بأرقام عربية وحق ملكية كاملة وتأكيد تطابق كل مدخل.
- التلاعب بكلفة البناء أو نوع الحق بعد إنتاج الملف يجعل الاستيراد HOLD.
- رفض أنواع البيانات المحرفة، والصنف غير المعروف، والتوقيع غير المتطابق، والمحاولة لحقن قيم اعتماد/نتائج مالية في ملف المدخلات.
- الحفاظ على بيانات الدراسة الحالية عند رفض الملف، وتصفير مخرجات العرض عند قبول ملف صحيح.
- فحص بوابات الإصدار والبناء والواجهة والجوال واستعادة بيانات المالك الأصلية، لتجنب تعطيل نظام الملفات الموجود في ستارتك.
